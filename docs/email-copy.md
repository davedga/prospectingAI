# Outreach email copy — what the bot actually sends

_Last updated: 2026-11-02. Source of truth: `src/lib/drafting.ts` (first touch) and `src/lib/followup-content.ts` (follow-ups). This document is generated by hand from those templates so the team can review the real copy without reading code._

## How the copy is produced

Every email is **generated per-contact by Claude**, not pulled from a fixed template string. What *is* fixed is the **structure and the rules** — the model fills in the brand, category, and TikTok Shop status, but it must follow an exact paragraph shape and a long list of hard constraints (`CLAIMS_DISCIPLINE` in `drafting.ts`). So the samples below are **representative** — the exact words vary per brand, but the shape, length, and framing are locked.

Key guardrails already enforced on every email:

- **First touch is deliberately simple** — 3 short paragraphs, no hero-SKU, no press, no retail detail. That detail is only allowed later in the sequence. (This is the opposite of "heavily AI-personalized hero-SKU messaging" — worth confirming against what the frontend is showing.)
- Never fabricate a number; prospect-specific figures (GMV, revenue, COGS) only if already in the record.
- One observation, one question mark per email.
- Greeting is always "Hey [First name],".
- Subject line format: **"[Brand] x DGA (TikTok Shop)"**.
- A signature block is appended automatically (configurable in Settings) — the model writes only up to "Best,".

## The sequence

The bot sends a **first touch** followed by up to three follow-ups (exact count = `sequenceLength` in Settings). Each touch has a distinct, fixed shape.
